# 📊 Mobile Phone MIS Dashboard (Power BI)

## 📌 Overview

This project is part of the **Power BI Projects Archive**, showcasing a recruiter‑ready dashboard for **Mobile Phone MIS (Management Information System)**. It highlights advanced analytics, KPI tracking, and professional storytelling with a clean, A4‑formatted layout.  

**Inspired by:** [Power BI Mobile Phone MIS Project on YouTube](https://youtu.be/qFLJqjLJxAY)

---

## 📂 Dataset

- **Source:** Mobile phone MIS records (sample dataset).  

- **Key Fields:**  

  - Product details (brand, model, category)  

  - Sales transactions (date, region, quantity, revenue)  

  - Customer demographics (age, location, preferences)  

  - Performance metrics (profit margins, growth rates)  

---

## ⚙️ Features

- **Interactive Dashboard:** Drill‑down by brand, region, and time period.  

- **KPIs:** Revenue, profit, units sold, customer acquisition.  

- **Trend Analysis:** Monthly/quarterly performance tracking.  

- **Comparisons:** Brand vs. brand, region vs. region.  

- **Data Storytelling:** Recruiter‑facing visuals with professional formatting.  

---

## 🚀 Usage

1. Clone the repository and switch to the **Mobile MIS** branch.  

2. Download the `.pbix` file.  

3. Open in **Power BI Desktop** (latest version recommended).  

4. Connect to the provided dataset or replace with your own MIS data.  

5. Export reports to **PDF/PowerPoint** for recruiter or stakeholder presentations.  

---

## 🛠️ Technical Highlights

- **Data Modeling:** Star schema with fact and dimension tables.  

- **DAX Measures:** Custom calculations for KPIs (e.g., `Total Revenue`, `Profit %`).  

- **Visualization:** Professional recruiter‑facing charts (bar, line, pie, cards).  

- **Formatting:** Exact **A4‑ready layout** for recruiter documentation.
