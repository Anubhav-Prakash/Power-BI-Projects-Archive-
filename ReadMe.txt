🌍 Global Air Pollution Data - AQI Analysis (Power BI Project)
📖 Overview
This project analyzes global air pollution data using Power BI to provide insights into Air Quality Index (AQI) trends across countries and regions. The dashboard highlights pollution levels, compares AQI categories, and enables interactive exploration of environmental data.
The goal is to visualize air quality patterns, identify high-risk regions, and support data-driven decision-making for environmental monitoring and policy.

📊 Features

- Interactive Dashboard: Explore AQI data across multiple countries and time periods.
- Data Modeling: Cleaned and structured dataset for efficient analysis.
- Visualizations:
- AQI distribution by country/region
- Trend analysis over time
- Comparative charts for pollutants (PM2.5, PM10, NO2, SO2, CO, Ozone)
- Filters & Slicers: Drill down by location, pollutant type, and AQI category.
- KPIs: Highlight critical metrics such as average AQI, worst-affected regions, and pollutant contributions.

🗂️ Dataset

- Source: Global air pollution datasets (publicly available environmental data repositories).
- Key Attributes:
- Country/Region
- Date/Year
- AQI value
- Pollutant concentrations (PM2.5, PM10, NO2, SO2, CO, Ozone)
- AQI category (Good, Moderate, Unhealthy, Hazardous)

⚙️ Tools & Technologies

- Power BI Desktop: Dashboard creation, DAX measures, and data modeling.
- Excel/CSV: Initial dataset cleaning and preprocessing.
- DAX: Custom measures for AQI categorization and pollutant analysis.

🚀 Getting Started

- Download the dataset (CSV/Excel format).
- Open the .pbix file in Power BI Desktop.
- Refresh the data source to load the latest dataset.
- Explore the dashboard using filters and slicers.

📈 Insights

- Identify countries with consistently high AQI values.
- Compare pollutant contributions across regions.
- Track improvements or deteriorations in air quality over time.
- Support environmental awareness and policy-making with clear visual evidence.

📌 Use Cases

- Students & Learners: Practice Power BI skills with real-world environmental data.
- Data Analysts: Build portfolio projects showcasing dashboard design and DAX usage.
- Policy Makers & NGOs: Use insights to advocate for cleaner air initiatives.
