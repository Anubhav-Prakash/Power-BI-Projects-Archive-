# ISRO Data Analysis Dashboard (Power BI)

## 📊 Project Overview
This project is an **end-to-end Power BI dashboard** analyzing ISRO (Indian Space Research Organisation) mission data.  
It was inspired by the tutorial [ISRO Data Analysis with Power BI](https://www.youtube.com/watch?v=lPifmAg6Bsw).  
The dashboard provides insights into ISRO’s satellite launches, mission types, and success rates, helping visualize India’s space achievements.

## 🎯 Objectives
- Explore **mission success vs. failure trends** over time.
- Analyze **launch vehicle performance** (PSLV, GSLV, etc.).
- Visualize **satellite categories** (communication, remote sensing, navigation).
- Track **launch frequency by year**.
- Provide interactive filters for **mission type, year, and vehicle**.

## 🛠 Tools & Skills Used
- **Power BI Desktop**
- **Power Query** for data cleaning and transformation
- **DAX Measures** for KPIs (success rate, mission count)
- **Custom Visuals** (bar charts, line charts, donut charts, maps)
- **Data Modeling** for relationships between mission attributes

## 📂 Dataset
The dataset was provided in the tutorial and includes:
- Mission name
- Launch year
- Launch vehicle
- Satellite type
- Mission status (Success/Failure)

*(If dataset is large, link externally instead of uploading directly.)*

## 📈 Key Insights
- ISRO’s **success rate has steadily improved** over decades.
- **PSLV** remains the most reliable launch vehicle with the highest number of missions.
- Communication and remote sensing satellites dominate ISRO’s portfolio.
- Mission frequency increased significantly post-2000, reflecting India’s growing space program.

## 🚀 How to Run
1. Download the dataset from the tutorial link.
2. Open Power BI Desktop.
3. Import the dataset and apply transformations.
4. Load visuals as per the dashboard design.
5. Interact with filters to explore insights.
